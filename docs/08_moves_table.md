# 08. 技の一覧表（自動で作る資料）

`npm run moves-table` で `data/game/moves.json` などから作る。**手で直さない**（直すのはデータ。直したら作り直す）。

- 最初に派生のつながり（タイプの技 → 派生技 → 固有技）、次に強さの順の早見表、最後に派生の前後を並べた数値の表。
- **強さの目安（単体）**: 1体の敵に当て続けたときの1秒あたりのダメージ（威力 × 数 × 1回で当たる回数 ÷ 再使用）。ボスへの強さ。
- **強さの目安（群れ）**: 群れの中で、1秒あたりに与えるダメージの合計の見込み。技の範囲（飛ぶ技は通り道、扇・円・線の広さ）に敵が何体入るかを、敵1体あたり 5000 の広さとして見積もる（1回の技で40体まで）。雑魚への強さ。
- **総合** = √(単体 × 群れ)。段階ごとに最大レベルの総合をそろえている（タイプの技 80・派生技 240・固有技 600。`data/game/move-balance.json`、`npm run balance-moves`）。
- どれも、ポケモンのステータス・タイプ一致・相性・持ち物は掛けていない。
- **大きさ**は当たり判定の半径、**距離**は狙える距離・前に出る距離・回る半径・ビームの長さ（出し方による）。

## 派生のつながり

左から タイプの技 → 派生技 → 固有技。各技の下の数は強さの目安（単体・群れ。Lv1 → 最大）。1つの技から2つに分かれるものは行を分け、2行目からは元の技を空けている。
