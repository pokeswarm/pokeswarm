# 06. 開発の順番と未決定事項

## 1. 方針

- 内容を作り込む前に、**方向転換につながる技術的な不安を先に検証する**。
- 各フェーズの終わりに作者が動作を確認してから、次のフェーズに進む。
- 最初の公開版はカントーステージのみ。
