# 22. 自分から円が出る技の作り直しの案（相談用）

作者の決定（2026年11月4日。07 の174章）: 自分を中心に丸い円が広がる技は面白みがない。新しい技では作らず、前からある技は少しずつ作り直す。初期の段階から止まったまま勝てるのはだめで、ビルドが完成してボスに備える段階の放置は許容する。

この文書は、今ある円の技を洗い出し、1 つずつ作り直しの案を出すもの（相談用）。決まったら 07 に章を足す。

**2026年11月4日: 作者が「のしかかりから順に」・だいばくはつ は例外、と決めた。その1（のしかかり・すてみタックル・じしん・マグニチュード・サイコキネシス・あくのはどう）は 07 の176章で作った。**作るときは次を守る。

- 向き・狙い・置き場所のどれかを持たせる（前へ飛ぶ・前の扇・敵の足元・敵へ追いかける・通った道に残る など）。
- 全方向が技らしさなら、ほうでん（07 の165章）のように「走っている間だけ」などの条件を付ける。
- 絵は新しく作る（使い回し・仮の見た目にしない）。噛む技は かみつく系統の絵（07 の175章）。
- 作ったら放置の確かめ（`src/sim/afk.balance.ts`）と技の DPS（`src/sim/moveDps.balance.ts`）を回す。

## 2. 作り直しの案

【案】は Claude の案。作者が「この形で」「別の形に」と表に書く。

| 技 | 案 | 原作らしさ・ねらい |
|---|---|---|
| **のしかかり** | 向いている方へ跳び上がり、**前の着地点**で押しつぶす（着地点の円。ひるみ・まひ はそのまま） | 体で乗る技。前へ出る分、近くの敵の群れへ突っ込む遊びになる |
| **すてみタックル** | 向いている方へ**突進し、通った道の敵に当たる**（前の細長い四角。反動はそのまま） | 捨て身で突っ込む。でんこうせっか の先の技らしく、前へ速く進む |
| **ギガインパクト** | 力をためて（0.4 秒）**前へ大きく突進**し、止まった所で大きな衝撃（前の扇）。再使用は長いまま | 重い一撃（07 の35章）を、前へ出る大技に |
| **ドラゴンダイブ** | 空へ跳び、**一番近い敵の所へ急降下**して衝撃（敵の足元に落ちる） | 原作の「上から突っ込む」。狙った所へ飛び込む |
| **じしん** | **向いている方の扇**に、地面の揺れの帯が進む（バークアウト と同じ扇の帯。164章） | 前の群れをまとめて揺らす。後ろは守らない |
| **マグニチュード** | 届く範囲の**ランダムな場所**で揺れが起きる（強さ 4〜10 で揺れの大きさが変わる。152章のランダムはそのまま） | どこで何が起きるか分からない楽しさ |
| **サイコキネシス** | **前の扇の中の敵を念でつかみ、向いている方へ投げ飛ばす**（つかまれた敵が光る） | 念で動かす。162章の「前へ押す」をはっきり前だけに |
| **あくのはどう** | 一番近い敵へ**黒い波動の玉**が飛び、当たると弾ける（ひるみ） | バークアウト（前の扇）と分ける |
| **ふんえん** | **走った跡に溶岩が流れ出て残る**（足あと型。止まっていると出ない） | 原作の「まわりを焼く」を、動き回るほど広がる形に |
| **ふんか** | 噴き上がった溶岩の塊が、**届く範囲のランダムな敵へ降り注ぐ**（足元の噴火の円はやめる。HP が多いほど数が多いのはそのまま） | 火山の噴火。降ってくる場所が散らばる |
| **とっておき** | 覚えている**ほかの技の数だけ光の玉**が出て、向いている方の扇へ飛んで弾ける | 「最後に取っておいた」大技。技を育てた数が見える |
| **だいばくはつ** | 【要決定】例外として今のまま（自分を中心に爆発するのが技そのもの。HP を使い、再使用が長い）か、**前へ転がって行って爆発**するか | 自爆の技。初期から放置はできない（HP を使う） |
| **フレアドライブ** | 炎をまとって**前へ突進**し、通った道が燃える（足あと型の炎が残る） | 突進の技 |
| **ほのおのうず** | **一番近い敵の所に炎の渦が立ち**、しばらく閉じ込めて焼く（その場から動けなくする） | 原作の「しめつけ」 |
| **マジカルリーフ** | 葉が**敵を追いかけて**飛ぶ（必ず当たる） | 原作の「必ず当たる」 |
| **カウンター** | 受けたダメージを、**触れてきた敵の方へ**衝撃として返す（その敵へ向けた扇） | 反撃の技。自分のまわり全部ではなく、殴ってきた相手へ |
| **ミラーコート・メタルバースト・マジックコート** | カウンター と同じ形（受けたら、その敵の方へ返す。それぞれの色と強さ） | ホウエン（ソーナノなど）。H5 の調整で一緒に |
| **リフレクター** | 向いている方に**光の壁**を立てる（前から来る敵を止め、触れると弾く） | 壁の技 |
| **リーフブレード** | 前の扇を**大きな葉の刃で斬る**（溜めはそのまま） | 斬る技。ホウエン |

## 3. 進め方の案

1. 使う系統が多い順に作る: のしかかり（54 系統）→ すてみタックル → じしん・マグニチュード → サイコキネシス・あくのはどう → ほかの固有技。
2. ホウエンの技（ミラーコート・メタルバースト・マジックコート・リフレクター・リーフブレード）は H5 の調整で一緒に見る。
3. 1 つ作るごとに、放置の確かめ・DPS・テストを回し、わざ見本帳で作者が見る。
