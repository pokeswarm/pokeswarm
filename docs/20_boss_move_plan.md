# 20. ボスの技と動きの作り直し（相談用。2026年11月3日）

作者の依頼（2026年11月3日）:「ボスの攻撃が一パターンになっている。ボスごとの固有のモーションも少なく、とりあえず突進することが多い。カントーの四天王以降、ボスのわざやモーションをアップデートしよう（色違い御三家は調整済み）」。

この文書は、今のボスの作りを数えた結果（1章）と、ボスごとの案（3〜7章）。**作者が案を選ぶ（○を付ける・直しを書く）→ Claude が実装する**。決まったら `07_content_draft.md` に章を足し、この文書は相談の記録として残す。

- 対象: カントーの四天王・ジョウトの四天王とワタル・レッド戦（ピカチュウ・エーフィ・カビゴン）・三犬・ルギア・ホウオウ・ホウエンの四天王とミクリ（27体）。
- 対象外: 色違いの御三家と、レッド戦3ラウンド目のフシギバナ・リザードン・カメックス（色違いと同じ技。調整済み）。カントーの伝説5体は 51章の**作者の案（【決定】）**なので、1章の表に載せるだけで案は出さない（変えたい所があれば言ってください）。ミュウは「ゆびをふる」でほかの技をまねるのが持ち味なので対象外。
- まだ作っていないボス（ホウエンのダイゴ戦3ラウンド・グラードン ＋ カイオーガ・レックウザ・デオキシス・ラティ兄妹）は H5 で、この文書の決まりで作る。ジムの中ボス（技を持たない）は 8章で聞く。

## 1. 今の作り（数えた結果）

技は `data/game/stage.json` の `moves`、だれが使うかは `data/regions/*.json` の `bosses[].moves`・`legendary.moveSets`。

**動き**: 対象のボスは全員、技の合間は「一番近いプレイヤーへまっすぐ歩く」だけ（`src/sim/systems/enemyMovement.ts`）。止まるのは予告の間（`rooted`）だけで、ボスごとの動き方は無い。伝説は速さ 160〜175 × 1.15（`legendSpeedMultiplier`）で、プレイヤー（180）より速いので、**技を使わなくても体当たりで追い続ける**。89.5 の【決定】「タッグの片方は距離を取って範囲技を撃つ役」も、まだ動き方としては作っていない（技の組み方だけ）。

**突進**: 27体のうち **16体が突進を持つ**（`legend-dash`・`zapdos-dash`・`moltres-flamedash` などの線に沿った体当たり）。

**借り物の技**: ほかのボスの技（ミュウツーのテレポート・サイコウェーブ、サンダーの突進、ファイヤーの炎の突進、リザードンのブラストバーン）や、タイプに関係ない共通の技を使っているボスが多い。特に **`legend-nova`（サイコキネシスの円。自分の周り）は 9体**、**`shadow-ball`（シャドーボール）は 7体**、**`legend-dash`（白い突進）は 5体**が使っていて、これが「一パターン」に見える一番の理由。

## 2. 作り直しの決まり（案）

1. **ボスごとに動き方を1つ持たせる**（技の合間の動き。下の「動き」の列）。今の「追う」のほかに、次の形を作る。
   - **間合いを保つ**: プレイヤーから決まった距離を保ち、横へ回り込む（タッグの遠くの役。89.5）。
   - **周りを回る**: プレイヤーの周りを円を描いて飛ぶ（クロバット）。
   - **動かない**: その場から動かず、テレポートで場所だけ変える（ネイティオ）。
   - **潜る・飛び去る**: 一時的に姿を消し（当たらない）、影や波紋だけがプレイヤーを追う（ゲンガー・ボーマンダ・ホエルオー）。
2. **技は、原作でそのポケモン（またはそのトレーナーの手持ち）が覚える技**から選ぶ。下の表の技は、全部 PokeAPI のデータで「そのポケモンがレベルかマシンで覚える」ことを確かめた。
3. **予告は必ずある**（赤い範囲）。予告の形と動きで避け方が分かるようにする（扇なら回り込む、伸びる線なら横へ、輪なら隙間へ、など）。
4. **突進は、そのポケモンの代名詞の技だけ**（ボルテッカー・しんそく・つじぎり など）。1体に1つまで、連続の狙い直しも減らす。タッグの「突進役」（89.5【決定】）は残すが、白い突進の写しではなく、その技らしい形にする（転がる・爪で踏み込む・潜って浮上する）。
5. **1技ずつ、その技だけの絵と当たりの演出を作る**（写し・使い回し・仮の見た目にしない）。同じ技を2体で使うときも、ポケモンが違えば絵を分ける（例外は 3.2 の質問）。
6. 数値（予告の秒数・範囲・威力・間隔）は【初期案】。第2段階・タッグの片方が倒れたときの速さ（今の `enrage`）はそのまま使う。
7. 新しい状態（動き方・消えている間・プレイヤーの「ねむけ」など）は、協力プレイでゲストへ送る形も一緒に作る（`09` 5章）。

**プレイヤーにかかる効き目**（新しく作る。どれも短く、避ければ受けない）:
- **ねむけ**: 2秒ほど移動が遅くなる（うたう・さいみんじゅつ・あくび）。
- **押し飛ばし**: プレイヤーが後ろへ飛ばされる（ほえる・ふきとばし）。
- **引き寄せ**: ボスや渦の方へ少しずつ引かれる（すなじごく・メロメロ）。
- **ひるみ**: 0.5秒ほど動けない（ねこだまし）。今の「凍る」（ぜったいれいど）を短くした形。
