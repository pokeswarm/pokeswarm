# 30. 遊べる伝説の作り直し（相談用）

作者の依頼（2026年11月18日）: 伝説ボスを一新したことで、倒して解放したプレイアブルの伝説がボスの迫力に比べて見劣りし、「せっかく倒したのにがっかりする」体験になっている。達成に釣り合う性能にする。DPS は上位帯になってよい。その代わりに技の演出も 1 つずつ高級にする。原作で覚える技かを調べ直してから、提案・作成に移る。

この文書は相談用。決まったら 07 に章を足す（次に出す版の章）。

**2026年11月18日: 作者が「案のまま」と答え、伝説は 1 体ずつ注文すると決めた。伝説は最初の技のセットを決める（決めた技だけを覚える）。固有技のルートが決まらない伝説は、最初から伝説の技を持ち、その技の強化の最大レベルを上げる。新しい仕組みのアクティブスキル（SPACE・Q・E で使う。回数とクールタイム）を入れる。1 体目のミュウツーは 5.1 の表と違う形で作った（07 の305章: サイコブレイク・シャドーボール・じこさいせい・みらいよち ＋ テレポート。はどうだん は却下）。2 体目のセレビィは 5.10 の案で作った（07 の306章: リーフストームの材料は リーフのいし → スペシャルアップ、4 枠目は いやしのねがい、スキルなし）。3 体目のスイクンは作者の案で作った（07 の307章: めいそう と、キーで使う なみのり・ミラーコート・ぜったいれいど。水が凍るコンボ）。4 体目のライコウは作者の案で作り直した（07 の309・310章: キーで使う しんそく〈SPACE〉・じゅうでん〈Q〉・ライジングボルト〈E〉と、びりびり を溜める エレキフィールド。重ねきった敵へのコンボ）。**作るのは 1 体ずつ、1 技ずつ localhost で撮って確かめ、作者の確認の後に次へ。
