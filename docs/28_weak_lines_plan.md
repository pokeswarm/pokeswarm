# 28. 下位の系統の救済と、上位の系統の調整（相談用）

作者の指示（2026年11月8日）: ミュウは覚える技が多すぎて理想の組み合わせを狙いにくく、伝説でもあるので外す。ゲンガーはナーフする（デバフと単体火力が強すぎる）。ピカチュウは許す（下げるとしても でんきだま の効果）。バンギラス・ハッサム・ヘルガーは微調整。**それよりも、下位の系統が弱すぎることのほうがバランスを崩している。下位の系統に有利な技を足して救済したい。**

この文書は相談用。決まったら 07 に章を足す。

**決まったこと（作者 2026年11月8日。07 の238章）**: 伝説は後回し。4.1（データだけで道を足す）は保留で、**技を足して救う**（8 章）。ころがる・つららおとし・ラスターカノンは作り直した。シャドーボールとシザークロスの破片は当たった相手に当たらないようにし、ヘドロウェーブの毒だまりはそのまま（動いているボスにはあまり効かない）。ストーンエッジ・だいもんじは威力を 1 割下げた。でんきだまは変えない。2〜5 章の数字は直す前のもの。

## 1. 数え方

- 強さは `npm run build-estimate`（`docs/27_build_estimate.json`。07 の237章）の見積もり。系統ごとの一番の案で、**伝説を倒す秒数の平均**を比べる。中央はカントー 18.0 秒・ジョウト 33.8 秒。「中央比」は中央の何倍の秒数か（大きいほど弱い）。帯は 0.5〜2 倍。
- 「本物」は `docs/25_boss_kill.json` の、本物の伝説戦（避ける時間・区切りの間を含む）の秒数。
- 「群れ」は `docs/24_build_dps.json` の群れ向けの案の DPS（中央との比。大きいほど強い）。ボスに弱くても群れに強い系統があるので、並べて見る。
- 技の「表の値」は `docs/26_move_items.json` の、ミュウ・ボス 1 体・持ち物（メトロノーム・マックスアップ・するどいツメ）込みの単体 DPS。系統の強さとは別に、技どうしを同じ物差しで比べるための値。
- 「足すと」の秒数は、`docs/16_learnsets.json` の写しに技を足して見積もりを回した値（`LEARNSET_IN`）。データを変えずに試せる。

## 3. 弱い理由

### 3.1 強い派生技に届かない（いちばん大きい）

派生技の表の値は、中央 587・上から 4 分の 1 で 918。なのに、次の 8 つだけが飛び抜けていて、**固有技の中央（1753）より強い**:

| 派生技 | 表の値 | 持つ系統 |
|---|--:|---|
| ハイパーボイス | 3623 | ラプラス・ニャース・ピィ・ニョロトノ・（ホウエン） |
| シャドーボール | 2558 | ゲンガー・（ホウエン） |
| ヘドロウェーブ | 2548 | ゲンガー・マタドガス |
| れんぞくぎり | 2278 | ストライク・ヘラクロス |
| エアスラッシュ | 2218 | 鳥・ドラゴンなど 13 系統 |
| はっぱカッター | 2187 | フシギダネ・ナゾノクサ・チコリータ |
| バレットパンチ | 1955 | ハッサム |

上位の系統は、強い固有技に加えてこの 8 つを 1〜3 つ持っている（ゲンガーは 3 つ）。下位の系統は 1 つも持たず、残りの枠が 300〜600 の技で埋まる。

## 4. 救済の案

### 4.1 原作で覚え、ゲームにある技を足す（データだけ。絵は今のまま）

覚える技の決まり（原作のレベル技と、自分のタイプかノーマルのわざマシン・教え技。タマゴ技は除く）を満たすものだけ。

| 系統 | 足す技（道） | 原作 | 今 → 足すと（中央比） |
|---|---|---|---|
| プリン | うたう ＋ シルクのスカーフ → ハイパーボイス（今ある派生の道をそのまま） | レベル技 | 28.9 → **13.5 秒**（1.61 → 0.81） |
| ププリン | 同じ | レベル技 | 60.0 → **28.1 秒**（1.78 → 0.85） |
| カビゴン | いびき ＋ シルクのスカーフ → ハイパーボイス（いびきの音が大きくなる） | 教え技 | 45.7 → **17.3 秒**（2.54 → 1.04） |
| カントーのヤドラン | サイコキネシス ＋ まがったスプーン → みらいよち（ヤドキングと同じ技） | わざマシン | 44.9 → **13.9 秒**（2.50 → 0.83） |
| オーダイル | ハイドロポンプ ＋ みずのいし → ハイドロカノン（カメックスと同じ技） | 教え技 | 66.5 → 51.3 秒（1.97 → 1.54） |
| ライコウ | でんこうせっか ＋ スピーダー → しんそく（ウインディと同じ技） | レベル技 | 74.9 → 60.7 秒（2.22 → 1.83） |

- プリン・ププリン・カビゴンは技が決まっている系統だが、どれも**今ある技（うたう・いびき）の先**に足すので、枠の数は変わらない。
- ハイパーボイスは 3.1 の飛び抜けた派生技。救済に使うなら、ハイパーボイスは今の強さのまま残す（あとで下げると、この 3 系統がまた落ちる）。
- 試して**効かなかった**もの: レアコイルの スピードスター → トライアタック（持ち物の枠が埋まっていて、するどいくちばし を持つとほかが下がる）。ポリゴンの でんじほう（技が決まっていて、元の でんきショック が無い）。

### 4.2 固有技を作り直す（ボスにも当たるように）

| 技 | 系統 | 案 |
|---|---|---|
| ころがる | ミルタンク | いちばん近い敵へ向かって転がり、当たったら跳ね返って同じ相手にまた向かう。当たるたびに大きく・速くなる（原作の「当たるたびに威力が上がる」）。ミルタンクは技が少ないので、これがいちばん効く |
| つららおとし | イノムー | 狙った敵の頭上につららを落とす（今はほとんど当たらない）。落ちた場所に砕けた氷が残る、など |
| ラスターカノン | レアコイル | ビームを太く、長く当て続ける。または 3 体のコイルが 3 本撃つ |
| サイコブレイク（伝説） | ミュウツー | 20 発のうち何発かは、いちばん HP の高い敵（ボス）に集まる |
| ぜったいれいど（伝説） | スイクン | 同じ。画面の敵を凍らせ、ボスには氷の塊が 1 つ落ちる、など |
| かみなり（伝説） | ライコウ | 4 つの落雷のうち 1 つは狙った敵に落ちる |

- 群れに強いところ（画面全体・ばらまき）は残す。ボスへの当たり方だけ足す。
- 落とす・集まる技でも、追いかける弾や必中にはしない（場所に落ちる・決まった向きに飛ぶ）。

### 4.3 新しい技を作る（原作のレベル技で、ゲームに無いもの）

| 系統 | 技 | 原作 | 案 |
|---|---|---|---|
| コダック | **しねんのずつき**（エスパー・ぶつり。固有） | ゴルダックのレベル技 | ねんりき ＋ まがったスプーン → しねんのずつき。頭痛の念の力をまとって前へ頭突き。コダックの初めての固有技 |

### 4.4 ポリゴン

技が決まっている（41章）ので、技は足さない。案: トライアタックが当たったら、3 色の小さな弾に分かれて周りの敵へ飛ぶ（群れに当たるように）。分かれた弾は、当たった相手には当たらない（ボスへの強さは今のまま）。

## 5. 上位の系統の調整

技の効き方を 1 つずつ抜いて測った（`効き方の分解`。ボス向けの案の合計と、その技 1 つだけの DPS）。

### 5.1 ゲンガー（カントー 0.42・ジョウト 0.46）

| 効き方 | 抜くと（技 1 つだけ・ボス） | 群れ |
|---|---|---|
| シャドーボール: 当たると 6 つに割れる | 8018 → 4393（**技の DPS の 45% が、ボスに当たる割れた弾**） | 19 万 → 18 万（ほぼ効いていない） |
| ヘドロウェーブ: 通り道に毒だまり | 7902 → 5301（**ボスが毒だまりに立ち続ける**） | 19 万 → 18 万 |

- どちらも、**群れのための効き方がボスに強く効いている**。ストーンエッジの破片を直したとき（当たった相手には当たらない `avoidTarget`）と同じ直し方ができる。
- 2 つとも直すと、案の合計 26807 → 約 20000。伝説の平均は カントー 7.5 → 約 10 秒（0.42 → 0.56）、ジョウト 15.6 → 約 21 秒（0.46 → 0.62）。
- 作者の言う「デバフ」: シャドーボールの ぼうぎょダウン（40%・3 秒）で、ほかの技の分が上がっている（シャドーボールを抜くと案の合計は、シャドーボール 1 つの DPS より 4300 多く下がる）。足りなければ、ボスへの ぼうぎょダウン を短くする。
- 同じ技を持つ系統も下がる: ヘドロウェーブは マタドガス（0.82）、シャドーボールは ホウエンの カゲボウズ・ラルトス（同じ技。固有技の道として持つ）。

### 5.2 ピカチュウ（カントー 0.52・ジョウト 0.78）

でんきだま（技の威力 ×2）を下げると:

| でんきだま | カントー | ジョウト |
|---|---|---|
| ×2（今） | 9.3 秒（0.52） | 26.5 秒（0.78） |
| ×1.75 | 10.6 秒（0.59） | 30.3 秒（0.90） |
| ×1.5 | 12.4 秒（0.69） | 35.3 秒（1.04） |

### 5.3 ハッサム・ストライク（ジョウト 0.57・カントー 0.66）

シザークロスの「終わりに割れる」破片が、ボスに当たっている。技 1 つだけのボスの DPS が 11386 → 5207（破片を抜くと半分以下）。群れは 36 万で変わらない。

- 破片が当たった相手を避けるようにすると、ハッサムの案の合計 19362 → 13337（0.57 → 約 0.83）。カントーのストライクも同じ技なので約 1.0 になる。
- 「微調整」なら、破片のうちボスに当たるのを半分にする（約 0.7）。
- バレットパンチ（派生 1955）は効き方の無い連打で、そのままでよい。

### 5.4 バンギラス（ジョウト 0.51）

ストーンエッジは、効き方（砕けた石の場所 +12%）ではなく、1 発の威力（151.8）で強い。同じ技を持つ イワーク（カントー 0.93）・ハガネール（0.73）も下がる。

- 案: 砕けた石の場所を抜く（ボス −12%。バンギラス 約 0.57）。または威力を 1 割下げる（約 0.57。イワーク 約 1.03・ハガネール 約 0.81）。

### 5.5 ヘルガー（ジョウト 0.60）

だいもんじ（固有。威力 229・貫通）の燃えた跡は、ボスには効いていない。強いのは威力そのもの。バークアウトは必ず こわがる（1.5 秒）。

- 案: だいもんじ のクールダウン 1.8 → 2.0 秒（約 0.65）。または、バークアウトの こわがる をボスには効きにくくする。

## 6. おすすめの順

1. **4.1 をそのまま入れる**（データだけ。プリン・ププリン・カビゴン・カントーのヤドランが中央付近まで上がる）。
2. **ころがる を作り直す**（ミルタンク。下位で一番遅く、技がこれしかない）。続けて つららおとし・ラスターカノン。
3. **コダックの しねんのずつき、オーダイルの アクアテール** を作る。
4. ゲンガーとシザークロスの「割れた破片・毒だまりがボスに当たる」を直す（ストーンエッジと同じ直し方）。でんきだま・ストーンエッジ・だいもんじ は数字で少し。
5. 伝説（ミュウツー・セレビィ・ライコウ・スイクン）は、作者が救うと決めたら 4.2 の作り直しと じんつうりき。

1 つ入れるたびに `npm run build-estimate`（数秒）で並びを見直す。作り直した技は `TABLE_REDO=技` で技の表を測り直す。
