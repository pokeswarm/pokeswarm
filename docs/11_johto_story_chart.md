## 3. 実装の前に分かったこと（J2 で直す所）

**J2 で直した（2026年10月27日）**: ボスの系統の縛りの検証を外した・ボスはジョウト用の別の ID（`johto-midboss-*`・`johto-boss-*`）・タイル ID は `johto_` 、曲は `johto-` を付けた・区間6 は2つの区間に分けた（6a は60秒）。**残り**: スウォームの区間を基準にした時刻（ウソッキーの囲い・区間6a のビリリダマとマルマインの高頻度）と、ランの長さ（今は仮に35分）は J5。

- **ボスの系統の縛りを外す**（60章）: 読み込み時の検証は `src/data/index.ts` の「ボスかスウォームの ……（またはその進化前）なので雑魚に出せません」。カントーの四天王の区間はすでに `allowBossSpecies` で外している。作者の指示は全体の話なので、検証そのものを外す。カントーの雑魚は、この縛りで外した種類（`01` のスウォームの項: ビードル・コクーン・ナゾノクサ・ケーシィ・ガーディ・ゴース・ドガース・ゴーリキー）を戻すかどうかを、作者に一度だけ聞く。
- **スウォームの時刻**: 今のスウォームは「ランの始めから何秒」（`atSeconds`・`untilSeconds`）。区間は中ボスを倒した時に進むので、ウソッキーの囲い・区間6a の高頻度・アンノーンの「区間1 から」は、**区間を基準にした時刻**（ボスと同じ `wave` ＋ `afterSeconds` の形）を足して作る。区間6 の途中で場面を切り替える仕組みも新しく要る。
- **ボスの敵 ID が重なる**: ジョウトのゲンガー（マツバ）・カイリキー（シバ）・カイリュー（ワタル）は、カントーの `boss-gengar`・`boss-machamp`・`boss-dragonite` と種族が同じ。強さと技が違うので、ジョウト用の別の ID にする。
- **タイル ID・曲の名前が重なる**: `meadow`・`cave`・`beach`・`elite_hall`、曲の `route`・`cave`・`forest`・`sea`・`victory-road`・`elite-four` はカントーにもある。J2 で `ground.json`・`bgm.json` を地方ごとに分けるか、名前に `johto_`／`johto-` を付ける。この文書では短い名前のまま書いている。
- **ランの長さ**: カントーは 25分（`stage.json` の `durationSeconds` 1500）で、四天王4人を約8分で倒す。ジョウトは 17:00 から四天王4人＋ワタル＋レッド（3ラウンド）なので、25分のままでは足りない。J5 でランの長さを作者に聞く。
- PokeAPI の出現データには、のちの世代の出現（ビッパ・コリンクなど）やサファリ・ポケスロンの出現が混ざる。`spawn.json` は手で書くので問題は無いが、自動で候補を作る場合は第2世代までに絞る。
