## 2. 決まっていること（07 の88章）

- 【決定】**特性**: ホウエン以降は、ポケモンごとに特性（いつも効くパッシブ）を持つ。
- 【決定】**性格**: ランの始めに抽選し、画面の右上に出す。ぼうぎょ・とくぼうを1つにまとめているので **16種類**（上げ下げするのは こうげき・ぼうぎょ・とくこう・すばやさ）。一覧は 88章。
- 【決定】**天気**: 昼・夜の代わりに天気を入れる。日差し・雨のほかにもいろいろな天気を巡らせ、特定のタイプが有利・不利になる。
- 【決定】**タッグバトル**: ボスは基本的に2体同時。ランの推奨人数は2人以上（マップ選びの画面に目安として出す。ソロも遊べる）。**ソロでもクリアできるように補正**（ボス1体ずつの HP を下げる。【初期案】2体の合計がカントー・ジョウトの1体の 1.3〜1.5 倍）。ソロで容易に突破できるようなら補正を戻す。
- ジョウトから引き継ぐ決まり: コインは共通、永続強化・ショップ・実績・記録・解放は地方ごと（ほかの地方の強化は効かない）。マップのタイルと曲は地方ごとに新しく作る（タイルはコードで描く・曲は Claude のオリジナルの 8bit）。

## 7. 守ること（詳しくは `09`）

- `src/sim/` は Phaser に依存させない。入力コマンドで進める。乱数はシード付き。データは `data/` に置いて型で検証する。文章は翻訳ファイル（6言語）、名前は PokeAPI。
- 新しい状態（性格・特性・天気・タッグのボス）を足したら、協力プレイでゲストへ送る形も一緒に作る（`src/net/sync.ts`）。当たったかは当てた人のブラウザで判定する。HP は本人のブラウザで管理する。
- 実績を足したら6言語の名前・説明も足す（無いとテストが全部落ちる）。
- 技を足したら `npm run balance-moves`（2回回すと落ち着く）と `npm run moves-table`。
- 名前は原作の言葉かゲーム内の用語。凝った言い換えは候補を見せてから。
- 書式を詰めた JSON を `JSON.stringify` で書き直さない（行を文字列で足す）。スクリプトは Write で `.cjs` に書いて node で実行する（Python は無い）。
- コミットは pokeswarm-dev（noreply のメール）。prettier は使わない。秘密情報をコミットしない。
- 作者とのやり取りは日本語。
