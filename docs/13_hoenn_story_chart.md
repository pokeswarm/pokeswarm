## 3. 実装の前に分かったこと（H2 で直す所）

- **区間を2つに分ける**: 区間3 は、ジョウトの区間6（いかりのみずうみ → こおりのぬけみち）と同じく、3a（60秒・中ボス無し）と 3b に分ける。区間の数は 16 になる（ジョウトと同じ）。
- **昼夜の代わりの天気**: 区間の `night` の代わりに `weather`（天気の ID）を持たせる。区間7 は、区間の中で天気を巡らせる形（`weatherCycle`: 天気の並びと秒数）が新しく要る。天気の効き方（タイプの威力・削る量・無効のタイプ・粒・色）は `data/` に天気ごとの定義を作る（ジョウトの伝説のマップの効果 `typePowerPct`・`weather.texture` を広げる）。
- **ボスの ID**: ジョウトと同じく `hoenn-midboss-*`・`hoenn-boss-*`。タッグは2体の組。エアームド（ナギ・ダイゴ）・ナマズン（区間13・14 の雑魚）のように同じ種族を何回も出すときは、別の ID（`hoenn-boss-skarmory-2` など）。
- **タイル ID・曲の名前**: `hoenn_`／`hoenn-` を付ける（この文書では短い名前で書いた）。
- **区間の雑魚に同じ種類をもう一度出す**: ジグザグマ（区間0・5）・グラエナ（5・6・9）・ヤミラミ（1・8・10）・ドゴーム（4・8）など。一度いなくなった種類は戻せない検証があるので、`zigzagoon-2` のような別の敵 ID にする（09 の1章 4）。
- **ドット絵**: 雑魚・ボスの新しい種族が多い（約70種）。SpriteCollab に歩きの絵があるかを H2 の `npm run sprites` で確かめ、無ければ雑魚を差し替える。
