## 1. 今の作り（数えた結果）

技は `data/game/stage.json` の `moves`、だれがどの技を使うかは `data/regions/*.json` の `bosses[].moves`・`legendary.moveSets` に書いてある。

**動き**: 対象のボスは全員、技の合間は「一番近いプレイヤーへまっすぐ歩く」だけ（`src/sim/systems/enemyMovement.ts`）。止まるのは予告の間（`rooted`）だけで、ボスごとの動き方は無い。伝説は速さ 160〜175 × 1.15（`legendSpeedMultiplier`）で、プレイヤー（180）より速い。そのため、**技を使わなくても体当たりで追い続ける**。89.5 の【決定】「タッグの片方は距離を取って範囲技を撃つ役」も、まだ動き方としては作っていない（技の組み方で分けているだけ）。

**突進**: 27体のうち **16体が突進を持つ**（`legend-dash`・`zapdos-dash`・`moltres-flamedash` など、線に沿って体当たりする技）。

**借り物の技**: ほかのボスの技（ミュウツーのテレポート・サイコウェーブ、サンダーの突進、ファイヤーの炎の突進、リザードンのブラストバーン）や、タイプに関係ない共通の技を使っているボスが多い。特に **`legend-nova`（サイコキネシスの円。自分の周り）は 9体**、**`shadow-ball`（シャドーボール）は 7体**、**`legend-dash`（白い突進）は 5体**が使っている。これが「一パターン」に見える一番の理由。

## 2. 作者が決めたこと（2026年11月3日）

1. **プレイヤーの技と名前や考え方が同じ技は、プレイヤーの技の演出を使ってよい**。「こいつもこの技を使えるのか」という驚きになる（例: レッドのカビゴンが ギガインパクト を使う）。仕組みは色違いの御三家と同じで、ボスの場所からプレイヤーの技を出す（`playerMove`・`casters`。07 の52章）。予告を付けて、プレイヤーへ向けて出す。下の表では **★** を付けた。
2. **これから作るボスの技は、後の地方の伝説でも使える部品にする**（形と数値はデータで決め、ボスの名前に結び付けない）。
3. **ボスの戦い方に、おおまかなバトルタイプを決める**（3章）。
4. **新しい地方でまた出るボスは、動きを別のものにする（強化）**。シバのカイリキー・ワタルのカイリューは、ジョウトではカントーと別の動きと技にする（前の版の質問 3.2・4.5 への答え）。

## 4. 作り直しの決まり（案）

1. **ボスごとに動き方を1つ持たせる**（技の合間の動き）。今の「追う」のほかに次の形を作る。どれも後の地方で使える部品にする。
   - **間合いを保つ**: プレイヤーから決まった距離を保ち、横へ回り込む（タッグの遠くの役。89.5）。
   - **周りを回る**: プレイヤーの周りを、円を描いて飛ぶ。
   - **動かない**: その場から動かず、テレポートで場所だけ変える。
   - **潜る・飛ぶ**: 一時的に姿を消し（当たらない）、影や波紋だけがプレイヤーを追う。
   - **跳ね回る**: 画面の端で跳ね返りながら走る（プレイヤーの ボルテッカー・ころがる の動き）。
2. **技は、原作でそのポケモンが覚える技から選ぶ**。下の表の技は全部、PokeAPI のデータで「そのポケモンがレベルかマシンで覚える」ことを確かめた（例外はピカチュウの ボルテッカー。教え技だが、原作でレッドのピカチュウが使う）。
3. **予告は必ず出す**（赤い範囲）。予告の形と動きを見れば避け方が分かるようにする（扇なら回り込む、伸びる線なら横へ、輪なら隙間へ、など）。
4. **突進は、そのポケモンの代名詞の技だけ**にし、1体に1つまでとする。タッグの「突進役」（89.5【決定】）は残すが、白い突進の写しにはせず、その技らしい形にする（転がる・爪で踏み込む・潜って浮上する）。
5. **★ の無い技は、1技ずつ、その技だけの絵と当たりの演出を作る**（写し・仮の見た目にしない。07 の152章）。★ の技はプレイヤーの技の演出を使い、予告だけボス用に足す。
6. 数値（予告の秒数・範囲・威力・間隔）は【初期案】。第2段階・タッグの片方が倒れたときの速さ（今の `enrage`）はそのまま使う。
7. 新しい状態（動き方・消えている間・プレイヤーの「ねむけ」など）は、協力プレイでゲストへ送る形も一緒に作る（`09` 5章）。

**プレイヤーにかかる効き目**（新しく作る部品。どれも短く、避ければ受けない）:
- **ねむけ**: 2秒ほど移動が遅くなる（うたう・さいみんじゅつ・あくび）。
- **やけど**: 数秒、少しずつ削られる。重ねて受けると長くなる（おにび）。
- **冷え**: 3回受けると短く凍る（こおりのいぶき）。
- **押し飛ばし**: プレイヤーが後ろへ飛ばされる（ほえる・ふきとばし）。
- **引き寄せ**: ボスや渦の方へ少しずつ引かれる（すなじごく・じゅうりょく）。
- **ひるみ**: 0.5秒ほど動けない（ねこだまし）。今の「凍る」（ぜったいれいど）を短くした形。
