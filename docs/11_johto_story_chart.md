## 2. 雑魚の候補の作り方（決めたこと・気づいたこと）

- PokeAPI の `location` → `area` の出現データ（金・銀・クリスタル・ハートゴールド・ソウルシルバー）から、歩いて出会うもの（なみのり・つり・いわくだき・あたま突きを除く）を集めて出現率の高い順に並べ、場所ごとの上位を拾った（確かめ用の一時スクリプトで取った。リポジトリには入れていない）。
- 取ったデータには、のちの世代の出現（ビッパ・コリンクなど）や、ポケスロン・サファリが混ざる。**第1〜第2世代のポケモンと、原作のその場所らしいものを優先**して手で拾った。本番では `targets.json` に入れる種のうち、世代の混ざりを自動で除く条件を決める必要がある。
- **雑魚に出せないポケモン**（`09` 1章 4: ボスとその進化前）。ジョウトのボス = ピジョン（ポッポ系）・ストライク・ミルタンク・ゲンガー（ゴース系）・ニョロボン（ニョロモ系）・ハガネール（イワーク系）・イノムー（ウリムー系）・キングドラ（タッツー系）・ネイティオ（ネイティ系）・クロバット（ズバット系）・カイリキー（ワンリキー系）・ヘルガー（デルビル系）・カイリュー（ミニリュウ系）・レッドの手持ち（ピカチュウ・ピチュー・エーフィ・イーブイ・カビゴン・ゴンベ・初代御三家の全系統）・三犬・ルギア・ホウオウ・セレビィ。
  - 原作のこの場所で一番多い **ホーホー・ズバット・ポッポ・ゴース・ミニリュウ・ウリムー・ワンリキー** は、ジョウトでは雑魚に出せない。この制約で上の候補は原作から少し外れた（洞くつにズバットがいない、など）。「ジムリーダーの相棒をボスにするか、原作どおりのズバットを雑魚に出すか」で迷う点は、**ボス側（10の4章）を優先**して雑魚を外した。
- 例外の確認事項（作者へ）: ヤドン（ヤドキングはプレイアブルの予定）・メリープ（プレイアブル）などは、プレイアブルの種族を雑魚にも出してよいか。カントーの扱いに合わせる。

### 生成のための指示文（共通の型。`<…>` を表の「見た目」に差し替える）

```
Seamless tileable top-down ground texture for a 2D pixel-art game.
Strict top-down orthographic view looking straight down (no perspective, no horizon, no sky).
Visible chunky pixel-art with a 128x128 pixel grid, limited palette of about 32 colors, no dithering, no anti-aliasing.
Subject: <見た目>.
Flat, even lighting with no vignette, no shadows cast across the whole image, no border or frame.
The left edge matches the right edge and the top edge matches the bottom edge so it tiles with no visible seam.
No characters, no buildings, no text, no large single object in the center; only small repeating details spread evenly.
Same art style, brightness and detail density as a classic Game Boy Advance era Pokemon overworld ground tile.
Output a square image.
```

- カントーの6枚と画風・明るさをそろえる。ポケモンの絵の邪魔をしないよう、**中くらいの明るさ・コントラストは控えめ**にする（ドットの細かさは 128×128 マスの感じ）。
- 出来上がったら、3×3 の並べたプレビューで継ぎ目と、ポケモンの絵が読み取れるかを一緒に確かめる。
