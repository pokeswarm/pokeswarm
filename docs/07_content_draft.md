# 07. フェーズ1の中身のたたき台（御三家）

フェーズ1（ソロの基本ループ）で、技・派生・固有技・進化の仕組みを作って確かめるための、最小限の中身のたたき台。御三家（フシギダネ・ヒトカゲ・ゼニガメ）の3系統で一通り遊べることを目標にする。

印（【決定】【初期案】【要決定】）の意味は `01_game_design.md` の冒頭を参照。このたたき台の内容は、特に書いていなければすべて【初期案】。数値はフェーズ1で、シミュレーションを速く回す道具と実際に遊んだ感触で決める。

名前のキーは PokeAPI の英語名（例: `ember`）にそろえ、表示する名前は PokeAPI の各言語の名前を使う（`02_architecture.md` 7章）。

---

## 1. 前提（決定済み）

- 技は最大4つ。**忘れられない**。枠が埋まったら、持ち物・パッシブ・技の強化から選ぶ（`01` 4.1）。
- 技は最大3段階: タイプの技 → 派生技 → 固有技（`01` 4.2）。
- 派生の条件は「元の技が最大レベル ＋ 材料の持ち物を持っている」。そろうと次のレベルアップの候補に必ず出る。派生した技は元の技と入れ替わる。
- 1つの技が2種類以上に派生できる。両方の材料を持っていても、選べるのは片方だけ。
- 進化は原作どおりのレベル。1ランの終わりの目安は、強化なしでレベル50。永続強化・パッシブ・上振れでレベル70〜100（`01` 3.1・5.2）。
- 固有技の条件は「派生技（最大レベル）＋ 持ち物」（`01` 4.2）。
- 進化の石は、進化・派生したときになくなる。イーブイなど石で進化するポケモンは、石が無ければ進化しない（`01` 5.2）。
- ノーマルタイプの技は、すべてのポケモンの候補に出る（`01` 3.3）。

## 2. 御三家の進化とタイプ

| 系統 | 進化 | タイプ | 最初に覚えている技 |
|---|---|---|---|
| フシギダネ | フシギダネ → Lv16 フシギソウ → Lv32 フシギバナ | くさ・どく（変わらない） | つるのムチ |
| ヒトカゲ | ヒトカゲ → Lv16 リザード → Lv36 リザードン | ほのお → リザードンで**ひこうが加わる** | ひのこ |
| ゼニガメ | ゼニガメ → Lv16 カメール → Lv36 カメックス | みず（変わらない） | みずでっぽう |

- 最初の技は、原作の最初の技（たいあたり・ひっかく）ではなく、タイプの技にする（最初からタイプらしさが出るように）。
- リザードンになると、ひこうタイプの技が候補に加わる（`01` 3.3）。

## 3. レベルの進み方（経験値の配分）

1ラン15分（カントー）での目安:

| 時間 | レベルの目安（強化なし） | 出来事 |
|---|---|---|
| 2〜3分ごろ | 16 | 1回目の進化 |
| 8〜10分ごろ | 32〜36 | 2回目の進化 |
| 15分（ボス） | 50 | 目安の到達点（カイリュー以外は進化し終わる） |
| 強化・上振れ | 70〜100（上限） | 永続強化・しあわせタマゴなどを重ねた場合。伝説とも戦える |

- 序盤ほど早く上がり、後半ほどゆっくりにする（序盤に技がそろい、後半はビルドの完成を目指す流れ）。
- 15分で50回のレベルアップは、平均すると約18秒に1回。強化して100近くまで上がると約9秒に1回になる。選択のたびにゲームが止まるので、多すぎると感じないか遊んで確かめる。

|---|---|---|---|
| ひのこ | プラスパワー | かえんほうしゃ（flamethrower） | 向いている方向へ扇形の炎を出し続ける。やけど |

| かぜおこし | スピーダー | エアスラッシュ（air-slash） | 空気の刃を数枚。ひるみ（確率） |
| みずでっぽう | クリティカット | ハイドロポンプ（hydro-pump） | 太い直線の水流。強いノックバック |
| あわ | ディフェンダー | なみのり（surf） | 自分を中心に広がる波。全方向に強いノックバック |
| つるのムチ | スピーダー | はなびらのまい（petal-dance） | 自分の周りに花びらが舞い、近くの敵に当たり続ける |
| はっぱカッター | プラスパワー | ソーラービーム（solar-beam） | ためてから太いビーム |
| やどりぎのタネ | ディフェンダー | ギガドレイン（giga-drain） | 近くの敵から吸い取り、与えたダメージの一部を回復 |
| どくばり | クリティカット | ヘドロばくだん（sludge-bomb） | 着弾すると毒の沼が残る（サンタウォーター型） |
| たいあたり | ディフェンダー | のしかかり（body-slam） | 跳び上がって着地の衝撃波。まひ（確率） |
| スピードスター | プラスパワー | はかいこうせん（hyper-beam） | ためてから画面を横切る太いビーム |

- ひのこは2つに派生する（かえんほうしゃ / ほのおのうず）。どちらを選ぶかでヒトカゲの戦い方が分かれる。
- ノーマルの技はどのポケモンでも使えるので、派生までにとどめる（固有技はポケモンごとのタイプの技から）。ノーマルタイプのポケモンの固有技は、そのポケモンを作るときに決める。
- 持ち物（プラスパワーなど）は複数の派生の材料を兼ねる。協力プレイでは「誰かが持っている持ち物は候補に出ない」（`01` 3.3）ので、材料の取り合いが起きる。役割分担の会話が生まれる点はよいが、遊んで確かめる。

### 4.3 固有技（3段階目）

| 系統 | 固有技 | 条件: 派生技（最大）＋ 持ち物 | 出し方・特徴 |
|---|---|---|---|
| ヒトカゲ | ブラストバーン（blast-burn） | かえんほうしゃ ＋ ほのおのいし | 前方に巨大な爆炎。焼け跡の地面がしばらく燃える |
| フシギダネ | ハードプラント（frenzy-plant） | ソーラービーム ＋ リーフのいし | 地面から巨大な根が次々に突き出る |
| ゼニガメ | ハイドロカノン（hydro-cannon） | ハイドロポンプ ＋ みずのいし | 画面を貫く巨大な水流。着弾点で大きな水しぶき |

- 固有技は、その系統のポケモンでなければ候補に出ない。

- 【決定】条件は「派生技（最大）＋ 持ち物」（案A）。派生技2つの合体（案B）は、自然な組み合わせの技が思いつかないため採らなかった。
- 固有技を覚えると、材料の石はなくなる（持ち物の枠が1つ空く）。
- ほのおのうずを選んだヒトカゲは、ブラストバーンに届かない（固有技への道は、かえんほうしゃ側だけ）。派生の選択に重みが出る。

## 5. 持ち物（派生の材料）

- 【初期案】持ち物の枠は4つ（技と同じ）。持ち物は重ねて取ると強くなる（最大5）。
- 持ち物は単体でも効果がある。そのうえで派生・固有技の材料になる。

| 持ち物 | 単体の効果 | 材料になる派生 |
|---|---|---|
| プラスパワー（x-attack） | 技のダメージ +10%（段ごと） | かえんほうしゃ、ソーラービーム |
| ディフェンダー（x-defense） | 受けるダメージ −8% | ほのおのうず、なみのり、ギガドレイン |
| スピーダー（x-speed） | 発射体の速さ・技の発動の速さ +10% | エアスラッシュ、はなびらのまい |
| クリティカット（dire-hit） | 急所の確率 +5% | フレアドライブ、ハイドロポンプ、ヘドロばくだん |
| もくたん（charcoal） | ほのおの技 +15% | （固有技の候補にもできる） |
| しんぴのしずく（mystic-water） | みずの技 +15% | |
| きせきのタネ（miracle-seed） | くさの技 +15% | |
| どくバリ（poison-barb） | どくの技 +15% | |
| するどいくちばし（sharp-beak） | ひこうの技 +15% | |
| ほのおのいし（fire-stone） | ほのおの技の範囲 +10% | ブラストバーン、イーブイ → ブースター |
| みずのいし（water-stone） | みずの技の範囲 +10% | ハイドロカノン、イーブイ → シャワーズ |
| リーフのいし（leaf-stone） | くさの技の範囲 +10% | ハードプラント |
| かみなりのいし（thunder-stone） | でんきの技の範囲 +10% | イーブイ → サンダース（御三家では使わない） |
| つながりのヒモ（linking-cord） | なし | 通信交換で進化するポケモン（ゴースト → ゲンガーなど）の進化。進化するとなくなる。ほとんどのポケモンには効果がないので、除外（BAN）の対象になりやすい |

- 石は重ねて取れない（最大1）。進化・派生したときになくなる。
- 協力プレイでは、誰かが持っている石は他の人の候補に出ない。石で進化するポケモンや、石が材料の固有技を狙う人がいるときは、誰が石を持つかの相談が生まれる（パーティプレイの要素）。

## 6. パッシブ（枠を使わない強化）

原作のドーピングアイテムなどの名前を借りる。それぞれ最大5段階。

| パッシブ | 効果 |
|---|---|
| マックスアップ（hp-up） | 最大HP |
| タウリン（protein） | 物理の威力 |
| リゾチウム（calcium） | 特殊の威力 |
| ブロムヘキシン（iron） | 防御 |
| インドメタシン（carbos） | 移動速度 |
| ポイントアップ（pp-up） | 技のクールダウン短縮 |
| ダウジングマシン（dowsing-machine） | 経験値の玉の取得範囲 |
| こうかくレンズ（wide-lens） | 技の範囲 |
| しあわせタマゴ（lucky-egg） | 経験値アップ（レベル100へ届く上振れの源） |

- 「発射数 +1」のパッシブも候補（Vampire Survivors のダプリケーター）。強すぎるので最大段階を小さくする。

- フェーズ1 区切り2 で、このたたき台の技・派生・固有技・持ち物・パッシブをすべてデータに入れた（`data/game/moves.json`・`derivations.json`・`items.json`・`passives.json`）。数値は仮で、バランス調整は後の課題。

## 9. フェーズ1で作るもの（このたたき台に必要な仕組み）

- 技の「出し方」: 一番近い敵へ / 向いている方向へ / ランダムな方向へ / 周回 / オーラ / 飛んで戻る / 扇形 / 直線のビーム / 突進 / 着弾で地面に残る
- 状態異常の部品の追加: やどりぎ（回復）、ねむり（ダメージで起きる）、ひるみ（ごく短く止まる）
- 技・持ち物・パッシブのレベルと強化表、派生と固有技の条件の判定、レベルアップの候補の作り方（必ず出る派生を含む。ノーマルの技は全員の候補に入れる）
- 持ち物の消費（石が進化・派生でなくなる）
- 進化（見た目・ステータス・タイプ・候補の変化）
- 経験値の表と、強化なしでレベル50の目安に合わせる調整の道具

## 10. フレンドリィショップ（永続強化）のたたき台（フェーズ2 区切り3）

`01_game_design.md` 8.3 の【決定】: ラン終了時にコインを獲得し、永続強化に使う。復活可能数・リロール数・候補の除外（BAN）を含む。**少し有利になる程度**にとどめる（初心者と熟練者が一緒に遊べる）。以下はすべて【初期案】で、値は `data/` で調整できるようにする。

### 10.1 コインの入り方（ラン終了時にまとめて。失敗でももらえる）

| 内容 | コイン |
|---|---|
| 生きていた時間 | 30秒ごとに 1 |
| 自分が倒した数 | 100体ごとに 1 |
| 中ボス（参加者全員） | 1体 10 |
| 四天王（参加者全員） | 1体 20 |
| クリア | 100 |
| 伝説を倒した | 150 |

目安: 20分でクリア（約8000体）なら約 40 + 80 + 80 + 80 + 100 = **約380**。10分で失敗なら約 **100**。

### 10.2 強化の一覧（費用は「基本の費用 × 次のレベル」。合計は約 3万コイン ＝ 約80ラン）

| 強化 | 1レベルの効果 | 最大 | 基本の費用 | 比べるパッシブ（ラン中・1レベル） |
|---|---|---|---|---|
| 最大HP | +4% | 5 | 100 | たいりょくのもと +10% |
| こうげき（物理の威力） | +3% | 5 | 150 | タウリン +8% |
| とくこう（特殊の威力） | +3% | 5 | 150 | ブロムヘキシン +8% |
| 防御 | +3% | 5 | 100 | リゾチウム +8% |
| 移動速度 | +3% | 3 | 150 | インドメタシン +6% |
| クールダウン | −2% | 3 | 300 | ポイントアップ −5% |
| 取得範囲 | +8% | 3 | 80 | ダウジングマシン +20% |
| 経験値 | +3% | 5 | 200 | しあわせタマゴ +10% |
| 復活可能数 | +1 | 2 | 1000 | （ラン中には無い） |
| リロール | +1 | 5 | 200 | （見送るとラン中に +1） |
| 候補の除外（BAN） | +1 | 5 | 200 | （ラン中には無い） |

- 協力プレイの復活可能数は、参加者全員の強化を合計して共有する（`01` 6章の【決定】）。リロール・除外は各自の強化を使う。
- **払い戻し**: 強化をすべて戻して、使ったコインを全額返す（ヴァンパイアサバイバーズと同じ。試し直しやすくする）。
- **候補の除外**: レベルアップの選択画面で、候補の1つを「除外」すると、その技・持ち物・パッシブはそのランでは二度と出ず、代わりの候補を引き直す（`01` 8.3）。キーは B を予定。

### 10.3 画面
- タイトル画面で S（ショップ）を押すとフレンドリィショップ。所持コイン・各強化のレベルと次の費用・買う・払い戻し。
- 結果画面に「獲得したコイン」を出す。

### 10.4 確認したいこと
- コインの入り方と、強化の効果・費用の大きさ（約80ランで全部、の目安でよいか）。
- 払い戻しを入れてよいか。

## 11. 解放するポケモンのたたき台（フェーズ4 区切り1）

【決定】（2026年10月21日、作者）解放したポケモンは**進化前の姿から始めて進化させる**。以下は、そのためのたたき台（特に書いていなければ【初期案】）。

### 11.1 系統と最初の技

| 解放の対象 | 始める姿 → 進化 | タイプ | 最初の技 |

## 12. 技の系統の作り直し（たたき台。2026年10月21日）

### 12.1 作者の方針（【決定】）
- **固有技を先に決め、そこから「類推できる一段手前の技」をさかのぼって作る**。
- 1つの系統（タイプの技 → 派生技 → 固有技）の中で、**技の特徴（出し方・持ち味）を一貫させる**。特徴がそろっていないと、強化したと感じられない。
- **材料の持ち物は、技の特徴に合うもの**にする（例: 急所に当たりやすい はっぱカッター は、クリティカットで派生する）。
- 派生技・固有技は、レベルアップの候補には**出さない**（派生でだけ手に入る）。
- 作者の例: つるのムチ（近接）＋クリティカット → はっぱカッター（自分の周りを切る・急所）＋材料 → はなびらのまい（固有技。自分の周りが強化される）。
- 作者の指摘: マタドガスのだいばくはつが、前の技と関係ない。

### 12.7 自分の体で攻撃する技・ピカチュウ（作者の追加。2026年10月21日）
- 【決定】自分の体で攻撃する技（たいあたり・でんこうせっか・ほのおのキバ・フレアドライブ・スパーク・ワイルドボルト・ボルテッカー）は、使うたびに**前方へ一瞬体を前後させて**タックルしているように見せる。当たり判定は**自分を中心にした前方の扇形**（前に置いた円はやめる）。

## 15. マップの障害物のたたき台（作者の案。2026年10月21日）

- 【決定】（作者）**はじめからアイテムをすべて使えるのではなく、遊んで実績を達成するとアイテムが解放されていく**（候補に出るようになる）。
- 【決定】（作者）御三家は、**固有技の一つ手前の派生に成功すると、固有技の材料（進化の石）が解放される**。例: かえんほうしゃ に派生 → ほのおのいし が解放。
- それにより **進化の石がアイテムの抽選に出るようになり、石で進化するポケモン（ガーディ・ナゾノクサ・ヒトデマン）も進化できる**ようになる。
- 23章の「報酬」の主な中身は、アイテムの解放にする（コイン・特殊なバフは、アイテムの解放が無い実績に）。

### 24.2 仕組み（案）
- 実績の `reward` に `item`（持ち物のキー）を足す。`achievements.json` の `initialItems` に、最初から使えるアイテムを書く。
- 候補を作るとき（`makeOffers`）、そのプレイヤーが解放していないアイテムは出さない。派生・固有技の材料でも、解放していなければ出ない（＝その派生はまだできない）。
- 協力プレイ: 候補はホストが全員分作るので、各自の解放したアイテムを、ショップの強化と同じく待合室で送る（`members/<番号>`）。**アイテムは各自が解放したものだけ**が、その人の候補に出る。
- 解放したアイテムは、実績の一覧の報酬（達成すると見える）と、結果画面・ラン中のお知らせ（「〇〇が 出るようになった」）で分かる。

### 24.3 最初から使えるアイテム（案。【要決定】）

## 25. 画面の大きさの調整とスマホのブラウザ対応のたたき台（作者の案。2026年10月22日）

### 25.1 作者の案
- 細かい UI の調整と、**スマホのブラウザ対応**（画面の比率と、WASD の代わりの**ジョイスティック**）を考える。
- **端末の画面の大きさによって、見える・見えないが変わる**ので調整する。

### 25.2 今の作り（調べて分かったこと）
- 拡大率は「画面の高さ ÷ 720」を 0.5 刻みに丸め、1 未満にはしない（`sprites.json` の `camera`）。そのため**見えるマップの広さが端末ごとに違う**:
  - 高さ 1080（フル HD）: 拡大 1.5 → 縦 720・横 1280（16:9 のとき）
  - 高さ 900: 拡大 1.5 → 縦 600 しか見えない（丸めで切り上がる）
  - 高さ 720 以下（小さいウィンドウ・スマホ）: 拡大 1 → 縦 545 など、狭い。横長のモニター（21:9）では横が広く見える
- 雑魚は自分から 720〜820 離れた所に出る（`spawn.json`）。見える範囲が広い端末では、**出てくる瞬間が見えてしまう**。狭い端末では、近くの敵が見えない。
- 移動の入力は 8方向（上下左右・斜め。`Axis` が -1・0・1）。シミュレーションと通信もこの形なので、ジョイスティックも8方向に丸めれば、ほかは変えなくてよい。
- 画面の文字・ボタンは、PC の画面を前提にした大きさ（レベルアップのカード・タイトルのメニュー・ログインの窓など）。

### 25.3 見える範囲のそろえ方（案。【要決定】）
| 案 | 中身 | 長所 | 短所 |
|---|---|---|---|
| **A（おすすめ）** | **見えるマップの広さを、どの端末でも同じ**にする（例: 横 1280 × 縦 720 のワールド）。画面の比率が違えば、余りは黒い帯 | 協力プレイでも全員が同じものを見る。敵の出る瞬間が見えない | 横長・縦長の端末では黒い帯が出る。拡大率が半端になり、ドットが少し不ぞろいになる（目立ちにくい程度） |
| B | 縦の広さだけそろえ（720）、横は端末の比率に合わせて広げる（最大 16:9 まで。それより横長なら黒い帯） | 黒い帯が少ない | 4:3 のタブレットなどは横が狭くなる |
| C | 今のまま（拡大率を 0.5 刻みに丸める） | ドットがいちばんきれい | 端末ごとに見える広さが違う（今の問題） |

- A・B のどちらでも、拡大率の丸め（0.5 刻み）はやめ、ちょうど収まる拡大率にする。
- HUD（経験値のバー・時間・アイコン）は、マップとは別に、画面の大きさに合わせた倍率で描く（小さい画面でも読める大きさを保つ）。

### 25.4 スマホのブラウザ（案。【要決定】）
1. **画面の向き: 横向きだけ**（おすすめ）。縦向きのときは「横にしてください」の画面を出す。ゲームが 16:9 の前提で作られているため。縦向きにも対応するなら、縦長の見える範囲を別に決める（25.3 と合わせて決める）。
2. **ジョイスティック: 触れた場所に出る**（おすすめ。左半分のどこを触っても、その場所が中心になる）。指を動かした向きを8方向に丸める。少しだけ動かしたとき（遊び）は止まる。右半分は空けておく（レベルアップのカードなどを押す）。
   - 別の案: 左下に固定の丸いスティックを出す（位置が分かりやすいが、指の位置を合わせる手間がある）。
3. **ボタン・カードの大きさ**: 指で押せる大きさ（44px 以上）。レベルアップのカードは、画面が狭いときは縦に並べる・1枚ずつめくる、など。
4. **全画面**: タイトルで「全画面で遊ぶ」を出す（ブラウザのアドレスバーが邪魔なため）。
5. **重さ**: スマホでは敵の上限（今は 1600）を下げる・効果の数を減らす、などの軽い設定を用意する。協力プレイのホスト（敵の計算を担う）は、PC を前提のまま（`03_network.md`）。

### 25.5 細かい UI の調整（気づいた点。作者の気になる点があれば足す）
- 小さい画面で、タイトルのメニューと右下のログインの窓が重なりやすい。
- 文の中の英数字（Press Start 2P）が日本語（美咲）より大きく見える。
- レベルアップのカードは、狭い画面で名前が折り返す。
- 協力プレイの待合室・フレンド・設定・ショップの画面は、色とフォントを替えただけ（原作風の作り込みはまだ）。

2. 25.4 のスマホの向き（横向きだけでよいか）と、ジョイスティックの出し方（触れた場所 か 左下固定 か）。

### 25.7 作者の決定と実装（見える範囲。2026年10月22日）
- 【決定】（作者）見える範囲は **B 案**: 見えるワールドの**縦の広さを、どの端末でも 720** にそろえる。横は端末の比率に合わせて広げるが **16:9 まで**。それより横長の画面（21:9 のモニター・横向きのスマホ）は、左右を黒い帯にする。

- まだ決めていないこと: 25.4（スマホの向き・ジョイスティックの出し方・軽い設定）、25.5 の UI の調整。

### 25.8 作者の決定と実装（スマホ。2026年10月22日）
- 【決定】（作者）おすすめのとおり: **スマホは横向きだけ**、**ジョイスティックは画面の左半分の触れた場所に出す**。

## 27. ほのおの技の見直し（作者の感想 2026年10月23日。ヒトカゲを遊んで）

- 【決定】ほのおのうず: 足あと（trail）をやめ、**自分のまわりを回る炎**（orbit。2個から、レベルで最大5個）。原作の「渦」のイメージ。
- 【決定】ほのおのキバ: レベルを上げても範囲が増えず、あってもなくても変わらなかった。**レベルで大きさと開き（角度）が広がる**ようにした（最大レベルの「反対側にも」はやめ、大きさと開きにした。進化先のフレアドライブを前だけにするため）。
- 【決定】かえんほうしゃ: ランダムな方向にばらまくのは解釈違い。**前へ細長い扇形（半径は長く、開きはとても狭い）の炎が噴き出す**（melee の扇形。開き 16°、長さ（半径）は Lv1 で約 280、最大で約 340。はじめはひのこの射程 520 にそろえたが長すぎた）。扇形の中のあちこちから炎の粒を出す。
- 【決定】フレアドライブ: 正面の直線（レーザー）は解釈違い。**前方の少し広い範囲を、突進して薙ぎ払う**近接（開き 120°。突進の見た目を大きく、残像つき）。
- 【決定】ゴッドバード: 直線をやめ、**進行方向へ飛んで戻ってくる往復（ブーメラン型）**。通った跡に燃える地面を残す（0.15秒ごと）。
- 【決定】ブラストバーン（作者 2026年10月23日）: **自分を中心に、円形の爆炎の柱が八方向へ広がる**。柱は**三段階で、内側から順に離れながら現れ**、遠ざかるほど半径が少しずつ大きくなる。新しい出し方 eruption（爆炎の柱）を作った: count 方向へ stages 段（`moves.json` の `eruption.stages`・`sizeGrowth`。ブラストバーンは 3 段・1段ごとに半径 +30%）、段の間は intervalSeconds（0.22秒）、いちばん外の段が range の距離。遅れて現れる柱は「出番を待つもの」（当たり判定の stage 3。待つ間は見えず当たらない）として置く。
- 見た目: 扇形の範囲は、開きが 60° より狭いと帯ではなく全体を塗る（`sprites.json` の `hitShape.sectorFullBelowDegrees`）。暖色を草の上に薄く重ねると茶色く濁るので、ほのおの技は塗りを濃くした（レシピの `projectile.shapeAlpha`。ほのお 0.65、かえんほうしゃ 0.7）。
- 威力は `npm run balance-moves` で段階ごとの目安に合わせ直した。
- 【決定】（作者 2026年10月23日）進化の決まり（22.3）の「射程が下がらない」は、**同じ出し方に進化するときだけ**当てはめる（大きさ・貫通・数・持続・再使用と同じ扱い）。出し方が変わる進化（ひのこのばらまき → かえんほうしゃの前への炎 など）は射程の意味が違うので比べない。ひのこの射程の値（520。狙う敵を探す範囲）にかえんほうしゃの長さをそろえて長すぎたため。ブラストバーンのいちばん外の段は 420 にし、画面に収まるようにした。

## 29. コインで買えるポケモン（作者の決定。2026年10月23日）

コインの使い道を増やすため、人気のポケモンをフレンドリィショップで買えるようにした（`data/game/shop.json` の `pokemon`。買うと解放され、払い戻しの対象外）。ポケモンを えらぶ 画面では、まだ買っていないポケモンに値段を出す。

|---|---|---|---|---|---|
| コダック | 2000 | 進化しない | みず（エスパーの技も覚える） | ねんりき | なし |
| プリン | 3000 | つきのいし → プクリン | **ノーマルだけ** | **はたく・うたう**（ほかの技は覚えない） | **おうふくビンタ**（はたく ＋ プラスパワー）・**ハイパーボイス**（うたう ＋ シルクのスカーフ） |

- 【決定】値段: イーブイ 15000・カビゴン 10000（コダック 2000・プリン 3000・ヤドン 3000 はたたき台のまま）。
- 【決定】コダックは ねんりき系（エスパー）で、みずの技も覚える（`playables.json` の `moveTypes`）。「ずつう」は原作に無い技なので作らない。
- 【決定】プリンは ノーマルだけ（`types`）。最初から はたく・うたう を覚えていて、**それ以外の技は覚えない**（`fixedMoves`）。はたく → おうふくビンタ（**往復するなぎ払いの近接**。新しい出し方 `sweep`）、うたう → ハイパーボイス（**自分を中心とするエリア**）。技が2つだけなので、はたく・うたう は派生技の強さにした（`move-balance.json` の `tierOverrides`）。【初期案】材料・数値。
- 【決定】ヤドンは なまける（回復）→ ドわすれ（回復 ＋ 防御アップ）で、**最初は攻撃の手段を持たない**（レベルアップで みず・エスパー の技を覚える）。新しい出し方 `heal`（`healPct`・`guardPct`）。【初期案】なまける: 4秒ごとに最大HPの 4%（最大 8%）、ドわすれ: 6秒ごとに 8% と 3秒のあいだ受けるダメージ −30%（最大 −40%・4秒）。
- 【決定】イーブイは、**かわらずのいし**（イーブイだけ・進化の石と一緒に持てない。威力・最大HP +10%・移動速度 +5%）を持つと進化しないで戦える。進化しないときだけ固有技の **とっておき**（覚えているほかの技 1つにつき威力 +15%）。**とっておきは とっておきな演出**にする: 虹色に切り替わる輪が外へ進み、縁から虹色のきらめきが出て、出た瞬間に画面がうっすら光る（`screenFlash`。目に優しいよう薄く短く）。**進化石で進化した後の固有技は無し**（そのタイプの技と派生で戦う）。
- 【初期案】カビゴンの ギガインパクト: 自分の周りに外へ進む大きな輪（強いノックバック）。
