# 19. 技進化で「ぶつり／とくしゅ」を入れ替えない案（相談用）

作者の指摘（2026年11月3日）: 技の ぶつり と とくしゅ が進化で入れ替わると、ビルドの方針が一気に狂う。

調べた結果: 派生 131 組のうち 30 組で入れ替わる（全体の派生 4・固有技のルート 26）。そのうち つるぎのまい・ビルドアップ は攻撃しない技なので、実際に困るのは 28 組。ヒノアラシ・ポッポ・ヒンバス・タマザラシ・ナックラーは本線で 2 回入れ替わる。

この文書は相談用。表の「案」に作者が直しを書く。決まったら 07 に章を足す。

## 1. 決まりの案

- 【案】**技進化（元 → 先）で ぶつり／とくしゅ を変えない**。テストで確かめる（攻撃しない技は除く）。
- 【案】系統の本線は、**最後の姿の こうげき と とくこう の高い方**にそろえる。差が小さい系統（5 以内）はどちらでもよい。支えの技のルートは、本線と別の分類でもよい（1 本のルートの中でそろっていればよい）。
- 直し方は 2 つ。
  - **分類の上書き**: `moves.json` の `damageClass`（ステルスロックで使っている仕組み）。原作と分類が変わるが、技の動きはそのまま。**使う系統が 1 つの技**か、使う系統がみな同じ寄りの技だけに使う。
  - **ルートの組み替え**: 多くの系統が使う技を上書きすると別の系統で入れ替わりが起きる所は、元の技を変える。
- 原作の分類（ゲーム内で表示する ぶつり／とくしゅ）と違ってよいか。★ 聞きたいこと。違ってよい前提で書いた。

## 4. まとめ

- 分類の上書き 21 技: とくしゅ に → つるのムチ・はっぱカッター・タネばくだん・どくばり・かえんぐるま・アクアテール（ヒンバス）・アイスボール・こうそくスピン・だいばくはつ・とっておき。ぶつり に → エアカッター・ふきとばし・ぼうふう・だいちのちから・りゅうのいぶき・ボルトチェンジ・あくび・ナイトバースト・てっていこうせん・どろかけ・マッドショット。
- ルートの組み替え 3: ウリムー（新しい技 こおりのつぶて）・タツベイ（いぶき → クロー → げきりん）・ルリリ（のしかかり → アクアテール）。
- テストを 1 つ足す（技進化で分類が変わらない。攻撃しない技は除く）。
- 威力の帯は変えない（分類が変わると、その系統の能力で威力が変わるので、DPS の表で確かめる）。
- ★ 聞きたいこと: (1) 原作と分類が違ってよいか。(2) くさ を とくしゅ でそろえてよいか。(3) ウリムー・タツベイ・ルリリ の組み替えと代わりの案のどちらか。
