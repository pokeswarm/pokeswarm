# 08. 技の一覧表（自動で作る資料）

`npm run moves-table` で `data/game/moves.json` などから作る。**手で直さない**（直すのはデータ。直したら作り直す）。

- 数値は「レベル1 → 最大レベル」。変わらないものは1つだけ書く。
- **強さの目安**: 1体の敵に当て続けたときの1秒あたりのダメージ（威力 × 数 × 1回で当たる回数 ÷ 再使用）。ポケモンのステータス・タイプ一致・相性・持ち物は掛けていない。周りを回る・地面に残る・ビームは持続の間ずっと当たり続けたとして数えるので、多めに出る。
- **大きさ**は当たり判定の半径、**距離**は狙える距離・前に出る距離・回る半径・ビームの長さ（出し方による）。
