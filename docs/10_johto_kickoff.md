## 5. 調べたこと（2026年10月27日）

- **SpriteCollab の動き**（`data/sprites/pipeline.json` の版 f18cffd）:
  - ピチュー（0172）: 動きが多い（Shock・Pain・Cringe・Faint・Tumble など）。
  - ピィ（0173）・ププリン（0174）: Walk・Attack・Sing・Shoot・Sleep・Hurt など。
  - **トゲピー（0175）: 泣く動き（Cry・Pain）は無い**。Walk・Attack・Strike・Dance・Appeal・Sleep・Hurt・Idle・Swing・Double・Hop・Charge・Rotate。泣き出す所は **Hurt（または Sleep）の動き＋自作のなみだのドット絵**で表す案。トゲチック（0176）には Pain・Cringe・LostBalance などがある。
  - カビゴンの眠りは `extraAnimations: ["Sleep"]` で取り込んだ（`data/sprites/pokemon.json`）。トゲピーも同じ形で Hurt などを足せる。
  - タマゴの絵は SpriteCollab から探していない。無ければ自作の 16×16 などのドット絵（道具の絵と同じ `data/render/items.json` の形）で作り、ひびが入って割れる演出にする。
- **今ある仕組みで作れるもの**（57章の対応）:
  - 技を使うたびに HP が減る: 技の `hpCost`（だいばくはつ: `pct`・`minHpPct`）。
  - ゆびをふる: 出し方 `metronome`（今はミュウの固有技: ものまね ＋ つきのいし）。ベイビィ用は「全部の技から抽選・再使用が長い」別の技にする。
  - つきのひかり（自分の周りの回復）: 出し方 `heal`（なまける など）。
  - 技を覚えない: プレイアブルの `fixedMoves`。進化で外す形は新しく足す。
  - 進化: 今はレベル・持ち物（石・つながりのヒモ）だけ（`src/sim/systems/evolution.ts`）。「たくさん歩くと進化」は新しい進化の条件（歩いた距離）を足す。PokeAPI ではピチュー・ピィ・ププリン・トゲピーの進化は「なつき」なので、`fetch-pokeapi.ts` の進化の条件の読み方も直す。
  - 箱の中身・実績で出るようになる物: 箱は `src/sim/systems/boxes.ts`、実績は `achievements.json`。PokeAPI の持ち物のキーは `silver-wing`・`rainbow-wing`（どちらもあることを確かめた）。

## 7. 守ること（カントーで分かったこと。詳しくは `09`）

- `src/sim/` は Phaser に依存させない。入力コマンドで進める。乱数はシード付き。データは `data/` に置いて型で検証する。文章は翻訳ファイル（6言語）、名前は PokeAPI。
- 新しい状態を足したら、協力プレイでゲストへ送る形も一緒に作る（`src/net/sync.ts`）。当たったかは当てた人のブラウザで判定する。
- ランごとの状態は Phaser のシーンの `init()` で戻す（前のランの絵を持ち越すと描画が止まる）。
- セーブの形を変えるときは「セーブを消さない」テストを通す。
- 技を足したら `npm run balance-moves`（帯から外す技は `exempt`）と `npm run moves-table`。
- 名前は原作の言葉かゲーム内の用語。凝った言い換えは候補を見せてから。
- コミットは pokeswarm-dev（noreply のメール）。prettier は使わない。秘密情報をコミットしない。
