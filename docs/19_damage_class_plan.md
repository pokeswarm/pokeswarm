# 19. 技進化で「ぶつり／とくしゅ」を入れ替えない案（相談用）

作者の指摘（2026年11月3日）: 技の ぶつり と とくしゅ が進化で入れ替わると、ビルドの方針が一気に狂う。技の分類をまるごと変えるのではなく、原作（PokeAPI）から**同じタイプ・同じ分類で、技進化の前後で威力が上がる組み合わせ**を探して差し替える。

**2026年11月3日: 作者が推しの案に決めた（クチートは メタルバースト、変化技は今のまま）。07 の161章で実装した。**

## 1. 調べ方と決まりの案

- 入れ替わる組: 派生 131 組のうち 25 組（攻撃しない技・原作の変化技 → とくしゅ のものは除いた）。
- 候補の探し方（`scripts` の調べる台本。PokeAPI のキャッシュ）: その系統が原作で**タマゴ以外**（レベル・わざマシン・教え）で覚える技のうち、
  - **先の差し替え**: 元と同じタイプ・同じ分類で、元より威力が高い技
  - **元の差し替え**: 先と同じタイプ・同じ分類で、先より威力が低い技
- 推しの選び方: ゲームにある技（◎）を優先。無ければ新しい技（新）。系統の最後の姿の こうげき／とくこう の高い方の分類を本線にする（差が小さい系統はどちらでもよい）。
- 【案】テストを足す: 技進化（元 → 先）で ぶつり／とくしゅ が変わらない。
- **原作で変化技（威力なし）の技**（ふきとばし・やどりぎのタネ・あくび）は原作に分類が無いので、この調べ方が使えない。ゲームでは今「とくしゅ」扱い。★ 聞きたいこと: 技を差し替えるか、その技だけ分類をルートに合わせて決めるか。下の表では両方を書いた。

## 4. まとめ

- 新しく作る技 7: ギガドレイン・どくづき・アシッドボム・ダブルウイング・あなをほる・こおりのつぶて・イカサマ（推しの場合）。どれも 1 技ずつ動きと絵を作る。
- 使わなくなる技 4: かえんぐるま・アクアテール（ヒンバスの版）・アイスボール・タネばくだん（キモリの このは の派生など、ぶつり のルートで使うかは別に決める）。
- 分類を決める変化技 3: ふきとばし・あくび（ぶつり）・やどりぎのタネ（差し替えるなら不要）。
- テストを 1 つ足す（技進化で分類が変わらない）。
- ★ 聞きたいこと: (1) 推しの方でよいか。(2) 原作の変化技は、分類をルートに合わせて決めてよいか。(3) クチートは ラスターカノン からでよいか、例外にするか。
